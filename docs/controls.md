# Controls

During the temporary Stage 1 cube scene, hold the right mouse button and drag
to orbit the camera, scroll to zoom, and press Escape to exit. These callbacks
will be replaced when the Input subsystem is integrated.

| State | Input | Action |
| --- | --- | --- |
| Customization | Scroll | Adjust helicopter size |
| Customization | Click color option | Select color |
| Flight | W / S | Move forward / backward |
| Flight | A / D | Move left / right |
| Flight | Right mouse drag | Orbit camera |
| Flight | Scroll | Zoom camera |

Helicopter size remains fixed during flight.
