# Controls

In the current helicopter scene, use W/S and A/D to move, hold the right mouse
button and drag to orbit, scroll to zoom, and press Escape to exit. Movement
uses fixed world directions and the helicopter leans toward its travel direction.

| State | Input | Action |
| --- | --- | --- |
| Customization | Scroll | Adjust helicopter size |
| Customization | Click color option | Select color |
| Flight | W / S | Move forward / backward |
| Flight | A / D | Move left / right |
| Flight | Right mouse drag | Orbit camera |
| Flight | Scroll | Zoom camera |

Helicopter size remains fixed during flight.
