# Controls

In the current helicopter scene, use W/S and A/D to move, hold the right mouse
button and drag to orbit, scroll to zoom, Space to ascend, Ctrl to descend,
Q/E to turn left/right, and Escape to return to the main menu. WASD acceleration
follows the helicopter's heading; existing momentum continues in world space.

| State | Input | Action |
| --- | --- | --- |
| Main Menu | Click Game Start | Open customization before flight |
| Main Menu | Click Sound Settings / Exit | Open audio controls / close the application |
| Customization | Scroll | Adjust helicopter size |
| Customization | Click size option | Select Small, Medium or Large |
| Customization | Click color option | Select color |
| Customization | Click Play | Fly with the selected color and size |
| Customization / Sound Settings | Click Back to Menu | Return to the menu and preserve settings |
| Sound Settings | Click or drag a volume slider | Adjust master, menu-effect or helicopter volume |
| Sound Settings | Click Mute Audio / Unmute Audio | Toggle audio |
| Menus | Escape | Close the application |
| Flight | W / S | Move forward / backward |
| Flight | A / D | Move left / right |
| Flight | Space / Ctrl | Ascend / descend |
| Flight | Q / E | Turn left / right (rudder) |
| Flight | Right mouse drag | Orbit camera |
| Flight | Scroll | Zoom camera |
| Flight | Escape / click Main Menu | Return to the main menu |

Helicopter size remains fixed during flight.
